# Trophy Navigator — руководство пользователя

GPS-навигатор для бездорожья, трофи-рейдов, ралли и туристического катания. Работает с онлайн- и офлайн-картами, импортирует точки, маршруты и треки в популярных форматах, ведёт мониторинг группы и запись треков.

Версия документа: 2.9.11 (стабильная), 2026-04-24

## Первый запуск

При первом запуске включается **14-дневный пробный период**. В нём доступны все функции без ограничений.

Когда пробный период подходит к концу, появится окно **«Пробный период заканчивается»** с указанием оставшихся дней. Кнопка **«Подробнее»** откроет [trophynav.ru](https://trophynav.ru), кнопка **«Позже»** — закроет напоминание.

После окончания пробного периода появится окно **«Пробный период завершён»**. Карта и навигация продолжат работать, но запись треков, экспорт и синхронизация будут отключены до активации лицензии.

## Главный экран

Карта занимает весь экран. Сверху расположена панель управления, снизу — виджеты (скорость, азимут, длина трека и др.). Состав и порядок виджетов настраивается.

### Верхняя панель

Слева направо:

| Кнопка | Назначение |
|--------|------------|
| **Компас** | Показывает текущий курс относительно севера. Тап по компасу — сброс ориентации карты на север. |
| **+** (Zoom In) | Приближение карты на один уровень. |
| **−** (Zoom Out) | Отдаление карты. |
| **Z…** (уровень зума) | Текстовый индикатор текущего уровня масштаба (можно включить в настройках). |
| **📍+** (Add Waypoint) | Добавить точку (waypoint) в текущем месте курсора. |
| **📂** (Quick Actions) | Открывает меню «Управление данными»: вкладки **WP / RTE / TRK / Files**. |
| **GO** | Старт навигации по активному маршруту. |
| **■** (STOP) | Остановить навигацию. |
| **🔋** | Уровень заряда батареи устройства (включается отдельно). |
| **Слои** | Открывает шторку выбора онлайн/офлайн-карты и оверлеев. |
| **REC** | Включить/выключить запись трека. |
| 🛰️ | Индикатор качества GPS (появляется при слабом сигнале). |
| ● | Индикатор связи с сервером мониторинга/Traccar. |
| 💬 | Сообщения от группы мониторинга (с количеством непрочитанных). |
| **⚙️** | Открывает экран настроек. |

### Замок экрана

Если включён в настройках, на экране появляется плавающая кнопка **🔒** для блокировки. После блокировки тапы по карте игнорируются, чтобы случайные касания на бездорожье не сбивали навигацию. Для разблокировки удерживайте кнопку (по умолчанию 3 секунды). Размер, прозрачность и положение кнопки настраиваются.

Альтернативно — длительное нажатие кнопки **громкость +** также блокирует/разблокирует экран (если включено в настройках).

### Виджеты внизу

Полоса виджетов в нижней части экрана. По умолчанию включены **скорость**, **азимут**, **длина трека**, **следующая КП**, **высота**, **хронометр**, **время**, **остаток до финиша (км)**, **имя следующей КП**, **трипмастер**, **батарея**.

Состав, порядок и видимость каждого виджета настраиваются в **Настройки → Основные → Виджеты на карте**. Высота нижней панели и размер шрифта — там же.

## Карты и слои

Нажмите кнопку **Слои** на верхней панели. Откроется шторка с тремя секциями:

- **ОНЛАЙН** — список доступных онлайн-карт (Google Sat, Yandex, OpenStreetMap, Топографические и др.). Выбирается одна.
- **ОФФЛАЙН** — список ранее скачанных офлайн-областей. Выбирается одна. Доступна только если карта скачана (см. раздел «Офлайн-карты»).
- **ОВЕРЛЕЙ** — слои, которые рисуются поверх основной карты (например, топография поверх спутника, мои треки, OSM-объекты). Можно включить несколько.

Кнопка **⟳ Обновить каталог** внизу шторки — синхронизирует список доступных источников с сервером Trophy Navigator (если включена облачная синхронизация).

Альтернативно — длительное нажатие кнопки **громкость −** переключает между текущей онлайн- и офлайн-картой (если включено в настройках).

## Точки, маршруты, треки

В Trophy Navigator три типа объектов:

- **WP (Waypoint)** — пользовательская точка (метка на карте).
- **RTE (Route)** — маршрут: упорядоченный список контрольных точек (КП), по которым ведётся навигация.
- **TRK (Track)** — записанный трек: последовательность GPS-координат во времени.

Управление всеми тремя — через кнопку **📂** на верхней панели (Quick Actions).

### Меню «Управление данными»

Открывается по тапу на 📂. Содержит четыре вкладки:

#### 📍 WP (жёлтая)

Список всех пользовательских точек. По тапу на точку — контекстное меню:
- **Показать на карте** — центрирует карту на точке.
- **Навигация к точке** — построить навигацию к этой точке.
- **Свойства** — координаты, описание, цвет, символ.
- **Переименовать**.
- **Удалить**.

Внизу вкладки:
- **📤 Экспорт GPX** — сохранить все точки в GPX-файл.
- **🗑 Очистить все** — удалить все WP (с подтверждением).

#### 🗺 RTE (оранжевая)

Активный маршрут. Показывает количество КП и длину в км. Кнопки:
- **👁 Показать / 👁 Скрыть** — видимость линии маршрута на карте.
- **▶ Старт / ⏹ Стоп** — начать или остановить навигацию.
- **🗑 Очистить** — удалить маршрут.

#### 📏 TRK (синяя)

Загруженный трек (например, из ранее записанного файла или импортированного PLT). Можно показать/скрыть, удалить, изменить цвет и толщину.

Стиль загруженного трека также можно поменять в **Настройки → Файлы → Стиль загруженного трека**:
- **Цвет трека** — палитра.
- **Толщина** — кнопки `−` и `+` (по умолчанию 3).

#### 📂 Files (серая)

Список ранее загруженных файлов и кнопка для импорта новых.

### Добавление точки

Тап по кнопке **📍+** на верхней панели — точка добавляется в место текущего курсора (центра карты). Сразу появится диалог имени, цвета и символа.

Чтобы добавить точку в произвольной локации — переместите карту так, чтобы курсор оказался в нужной точке, затем нажмите 📍+.

### Действия с точкой на карте

Длительное нажатие на точку открывает меню:
- Переместить
- Удалить
- Изменить свойства
- Поделиться
- Назначить цвет / символ

## Импорт файлов

### Поддерживаемые форматы

| Формат | Что содержит |
|--------|--------------|
| **GPX** | Точки, маршруты и треки (стандартный формат) |
| **WPT** | Точки (Ozi Explorer) |
| **RTE** | Маршруты (Ozi Explorer) |
| **TRK** | Треки (Ozi Explorer) |
| **PLT** | Треки Garmin/Ozi |
| **.sqlitedb / .mbtiles / .db** | Офлайн-карты (большие файлы тайлов) |

### Как импортировать

1. **Из меню «Файлы»**: кнопка **📂** → вкладка **Files** → выбрать файлы.
2. **Из Настроек**: **Настройки → Файлы → 📂 Загрузить файл**.
3. **Открыть из системы**: при тапе на GPX/WPT/RTE/TRK/PLT в файловом менеджере, мессенджере или почте — выберите Trophy Navigator.

После импорта появится Toast-сообщение:
- «📍 Загружены точки: N»
- «🗺 Загружен маршрут: N КП»
- «🛤 Загружен трек: N точек»
- «🗺 Карта загружена: …» (для офлайн-карт)

Если формат не распознан или файл пустой — «Файл пустой или формат не распознан».

Можно загрузить **до 50 файлов за раз**.

> **Важно.** При импорте отбрасываются некорректные координаты (в том числе «Null Island» 0,0). Заголовки и метаданные Ozi PLT фильтруются автоматически.

## Запись трека

Тап по кнопке **REC** на верхней панели — старт записи. Иконка сменится на красную, в нижней панели появится длина текущего трека и хронометр.

Повторный тап по REC — остановка записи. Появится диалог сохранения с предложением имени файла.

Если приложение закрывается во время записи — появится диалог «**Идёт запись трека**» с кнопками:
- **Сохранить и выйти**
- **Выйти без сохранения**
- **Отмена**

## Навигация по маршруту

1. Загрузите маршрут (RTE или GPX с маршрутом) или составьте его вручную.
2. Откройте 📂 → **RTE** → нажмите **▶ Старт**, либо нажмите **GO** на верхней панели.
3. Прибор будет вести к ближайшей КП, отсчитывая расстояние и азимут. Эти данные показываются в виджетах **NextCP**, **NextCPName**, **RemainKm**.
4. По достижении КП (вход в радиус КП) автоматически переключится на следующую.
5. По прохождении последней КП появится окно **«🏆 Маршрут завершён!»** со статистикой.
6. Чтобы остановить навигацию — нажмите **■** (STOP) или **▶ Стоп** во вкладке RTE.

Если приложение было закрыто во время навигации — при следующем запуске появится окно **«▶ Продолжить навигацию?»** с предложением возобновить.

### Радиус взятия КП

В **Настройках** задаётся радиус, при попадании в который КП считается взятой. Радиус маршрута и радиус пользовательских точек настраиваются раздельно (с версии 2.9.8 они разведены по слоям).

## Редактор трека

Открывается на любом загруженном или записанном треке. Сверху появится синяя панель **«✏️ Редактор трека»**.

Кнопки:
- **✓ Сохранить** (зелёная) — применить изменения.
- **✕** — выйти без сохранения.
- **✂ Обрезать** (красная) — отрезать часть трека (выбираете точку, остальное удаляется).
- **⎘ Упростить** (синяя) — уменьшение количества точек по алгоритму Дугласа–Пекера, со снижением размера файла.
- **↩ Отмена** (оранжевая) — откатить последнее действие.
- **⇄ Реверс** (фиолетовая) — развернуть направление трека.

При тапе на отдельную точку трека появится попап:
- **📍 Переместить**
- **🗑 Удалить**
- **✕** — закрыть

## Офлайн-карты

Полезны там, где нет интернета — на бездорожье, в лесу, в роуминге.

### Скачивание новой области

1. Откройте шторку **Слои** и выберите онлайн-карту, которую хотите скачать.
2. Перейдите в **Настройки → Карты** → область офлайн-карт.
3. Нажмите кнопку загрузки и выберите способ:
   - Прямоугольник вокруг текущей области карты;
   - Произвольный полигон (рисуете на карте).
4. Выберите диапазон уровней зума.
5. Подтвердите. Появится оценка размера в МБ и примерное время.
6. Запустится фоновое скачивание. Прогресс отображается в **Настройках** (процент и счётчик плиток) и в виде индикатора на карте — оба обновляются в реальном времени.

### Управление загруженной областью

Каждая область — карточка с названием, метаданными (например, «Google Sat + Топо 250м»), статусом и кнопками:

- **Открыть** — показать область на карте и сделать её активной.
- **Слои** — управление оверлеями для этой области.
- **Продолжить** — возобновить, если скачивание было приостановлено.
- **Удалить** — стереть область с диска.

Скачивание можно поставить на паузу, отменить, удалить и возобновить — в любой момент. С версии 2.9.11 переходы между этими состояниями стабилизированы: следующая загрузка не сломается, даже если предыдущую прервали.

## Группы мониторинга

Позволяют видеть на карте позиции других участников группы (друзей, экипажей).

### Список групп

Открывается из настроек или из бокового меню.

Сверху:
- **‹** — назад
- **Группы мониторинга** — заголовок
- **+ НОВАЯ** (оранжевая) — создать группу

Если не привязан email — появится подсказка: *«Синхронизация появится после привязки email в Настройках → Облачная синхронизация»*.

Если групп нет: *«У вас ещё нет групп. Нажмите «+ НОВАЯ» чтобы создать первую…»*.

### Карточка группы

- Цветной кружок — цвет группы.
- Название.
- Количество участников («3 участн.»).
- Бейдж **АКТИВНА** (зелёный) — если эта группа сейчас выбрана активной.
- **⋮** (три точки) — меню:
  - **Сделать активной**
  - **Дублировать**
  - **Удалить**

### Редактирование группы

Сверху:
- **‹** — назад
- **Редактирование** — заголовок
- **СОХРАНИТЬ** (оранжевая)

Поля:
- **НАЗВАНИЕ** — до 32 символов. Подсказка: «Например, Ралли».
- **ЦВЕТ** — палитра.
- **УЧАСТНИКИ** — список добавленных участников. У каждого — имя, уникальный ID, статус (Online/Offline/Last seen) и кнопка **×** для удаления.
- **+ ДОБАВИТЬ УЧАСТНИКОВ** (оранжевая) — открыть диалог поиска и добавления.
- **УДАЛИТЬ ГРУППУ** (красная, внизу) — удалить с подтверждением.

## Облачная синхронизация

Хранит точки, маршруты, треки и группы на сервере Trophy Navigator, чтобы они появлялись на других устройствах (например, в Trophy Navigator Desktop).

### Привязка email

1. **Настройки → Сеть → Облачная синхронизация**.
2. Введите ваш email.
3. Получите **Sync Key** — длинный ключ, который автоматически копируется при касании.
4. Введите этот же email и Sync Key на других устройствах (Desktop, второй телефон).

После привязки:
- Точки, треки и маршруты периодически синхронизируются в обе стороны.
- Группы мониторинга становятся доступны.
- Каталог карт можно обновлять с сервера.

### Возможные сообщения

- *«Группы обновлены с другого устройства. Загружаю свежую версию.»* — на другом устройстве вы поменяли список групп; приложение автоматически подтянет изменения.
- *«Нет связи — сохранено локально»* — изменения записаны, отправятся при появлении сети.
- *«Нет связи — показаны кэшированные группы»* — сеть пропала, отображается локальная копия.
- *«Слишком много изменений — подождите»* — лимит частоты, подождите несколько секунд.
- *«Ошибка авторизации sync»* — неверный email или Sync Key. Перепроверьте.

## Отправка координат на сервер 

Позволяет передавать вашу позицию на собственный или арендованный сервер Traccar — для онлайн-трекинга экипажа во время гонки.

### Настройка

**Настройки → Сеть → Traccar:**

- **Отправка GPS на сервер** — переключатель.
- **URL сервера** — например `https://traccar.example.com:5055`.
- **ID устройства** — уникальный идентификатор, заранее зарегистрированный на сервере Traccar.

### Индикатор статуса

Точка на верхней панели меняет цвет:
- **Зелёная** — успешно отправлено («📡 ✓ Онлайн»).
- **Жёлтая** — идёт отправка («📡 ↑ Отправка…»).
- **Серая** — ожидание GPS («📡 Ожидание GPS»).
- **Красная** — ошибка связи («📡 ✗ Ошибка связи»).

Если связь временно пропала, точки буферизируются на устройстве и отправляются пакетом при восстановлении сети.

## Кнопки громкости и блокировка экрана

В Trophy Navigator кнопки громкости перенастроены для использования на бездорожье — когда экран мокрый или пользователь в перчатках.

**Настройки → Основные → Управление:**

- **Кнопки громкости — зум** (по умолчанию вкл.) — короткое нажатие Vol+ приближает, Vol− отдаляет.
- **Блокировка экрана (Volume+)** (по умолчанию вкл.) — длительное нажатие Vol+ блокирует/разблокирует экран.
- **Переключение карт (Volume−)** (по умолчанию вкл.) — длительное нажатие Vol− переключает между текущей онлайн- и офлайн-картой.

### Кнопка-замок на экране

- **Показывать замок на экране** (по умолчанию вкл.).
- **Размер кнопки замка** — 1…10 (по умолчанию 3).
- **Прозрачность кнопки** — 10…100 % (по умолчанию 100).
- **Зафиксировать положение** — если выкл., замок можно перетаскивать пальцем.
- **Удержание для разблокировки** — секунды, по умолчанию 3.

## Частые вопросы

**Курсор «прыгает» — что делать?**
Увеличьте **Сглаживание GPS** в *Основные → Управление* (например до 7–8). При этом курсор будет двигаться чуть с задержкой, но плавнее.

**Карта не вращается по движению.**
Проверьте режим следования: *Основные → Режим следования → Следить — курс вверху*.

**Скачал офлайн-карту, но при отключении интернета карта серая.**
Откройте шторку **Слои** и выберите карту в секции **ОФФЛАЙН** (а не в **ОНЛАЙН**). Также убедитесь, что текущий уровень зума попадает в диапазон, который вы скачали.

**Не приходят точки от других участников группы.**
Проверьте: (1) email привязан в *Настройки → Сеть → Облачная синхронизация*; (2) группа активна (бейдж **АКТИВНА** на её карточке); (3) у участника тоже включена синхронизация и он добавлен в эту же группу.

**Импортированный GPX «потерял» часть точек.**
Точки с координатами 0,0 («Null Island») и некорректные значения автоматически отбрасываются. Это сделано специально, чтобы битые файлы не ломали карту.

**Маршрут не завершается, хотя я доехал до последней КП.**
Уточните радиус взятия КП в настройках. Если КП на узкой дороге — маленький радиус (10–30 м). На бездорожье — 50–100 м.

**Запись трека продолжается в фоне?**
Да. Запись идёт даже при выключенном экране, фоновое уведомление видно в шторке. При выходе из приложения во время записи появится диалог с предложением сохранить.

**Где найти ID устройства для Traccar?**
*Настройки → О программе → ID устройства*. Этот ID нужно зарегистрировать на сервере Traccar.
